# AI Cinema Prototype

A polished front-end prototype for an AI-only movie marketplace and streaming platform.

## Features
- React + TypeScript + Vite + Tailwind CSS
- Viewer experience with featured hero, curated sections, and movie grid
- Movie detail modal with trailer and purchase placeholder flows
- Creator portal with multi-step onboarding flow
- Creator dashboard with mock review, revenue, and upload status
- Responsive, premium dark UI with cinematic styling

## Files
- `src/App.tsx` — main application routes and flow state
- `src/components` — reusable UI components
- `src/data/movies.ts` — mock AI film data
- `src/types.ts` — application data types

## Run locally
1. Install Node.js from https://nodejs.org
2. Open this folder in a terminal
3. Run `npm install`
4. Run `npm run dev`

> Note: Payment processing, KYC, video hosting, and uploads are mocked in this prototype.
